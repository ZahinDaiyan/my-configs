01
Prerequisites — Install Everything First

Run these in an elevated PowerShell 7 window. winget handles almost everything.

powershell
# ── Winget install all core tools ──────────────────────
winget install --id JanDeDobbeleer.OhMyPosh  -e
winget install --id sxyazi.yazi               -e
winget install --id Neovim.Neovim             -e   # skip if already done
winget install --id BurntSushi.ripgrep.MSVC   -e   # needed by yazi/nvim
winget install --id sharkdp.fd                -e   # fast find, yazi dep
winget install --id ImageMagick.ImageMagick   -e   # image preview in yazi
ℹ

If winget is missing, install it from App Installer in the Microsoft Store. All packages above go to your PATH automatically.

02
Nerd Font — JetBrains Mono NF

Oh My Posh prompt glyphs require a Nerd Font. JetBrains Mono Nerd Font is the best pairing for your existing Neovim setup.

powershell
# Install via Oh My Posh font manager (easiest way)
oh-my-posh font install JetBrainsMono

# Or install manually from nerdfonts.com and place in:
# C:\Windows\Fonts\   (system)
# %LOCALAPPDATA%\Microsoft\Windows\Fonts\  (user)

Then in Windows Terminal: Settings → your PowerShell profile → Appearance → Font face → JetBrainsMono Nerd Font. Also set it in your Neovim GUI font setting.

✓

Recommended font size: 13–14pt, line height 1.2. Enable ligatures in Windows Terminal for the best look.

04
Oh My Posh — Prompt & Status Bar

Oh My Posh renders your prompt and the bottom status bar (called a transient prompt + right-side segments). We'll use the Catppuccin-flavoured catppuccin theme as base, then customise it.

powershell — download base theme
# Create config directory
New-Item -ItemType Directory -Force ~/.config/ohmyposh

# Download the Catppuccin Mocha OMP theme
Invoke-WebRequest `
  "https://raw.githubusercontent.com/JanDeDobbeleer/oh-my-posh/main/themes/catppuccin_mocha.omp.json" `
  -OutFile ~/.config/ohmyposh/theme.json

05
PowerShell Profile — $PROFILE

This is the heart of the setup. Open $PROFILE in Neovim (nvim $PROFILE) and paste the block below.

powershell — $PROFILE
# ════════════════════════════════════════════════════════
#  PowerShell 7 — Dev Profile   (Catppuccin + Oh My Posh)
# ════════════════════════════════════════════════════════

# ── Oh My Posh prompt ──────────────────────────────────
oh-my-posh init pwsh --config "$env:USERPROFILE\.config\ohmyposh\mytheme.omp.json" | Invoke-Expression

# ── PSReadLine (better editing) ────────────────────────
Import-Module PSReadLine
Set-PSReadLineOption -EditMode Vi                        # Vi keys! (use Emacs if preferred)
Set-PSReadLineOption -PredictionSource HistoryAndPlugin
Set-PSReadLineOption -PredictionViewStyle ListView
Set-PSReadLineOption -BellStyle None
Set-PSReadLineOption -HistorySearchCursorMovesToEnd
Set-PSReadLineKeyHandler -Key Tab            -Function MenuComplete
Set-PSReadLineKeyHandler -Key UpArrow        -Function HistorySearchBackward
Set-PSReadLineKeyHandler -Key DownArrow      -Function HistorySearchForward
Set-PSReadLineKeyHandler -Key Ctrl+d         -Function DeleteCharOrExit

# ── Terminal colours (Catppuccin Mocha exact) ──────────
$Host.UI.RawUI.BackgroundColor = 'Black'   # let transparency show
Set-PSReadLineOption -Colors @{
  Command            = '#89b4fa'   # Blue
  Parameter          = '#fab387'   # Peach
  Operator           = '#89dceb'   # Sky
  Variable           = '#cba6f7'   # Mauve
  String             = '#a6e3a1'   # Green
  Number             = '#f9e2af'   # Yellow
  Member             = '#89dceb'   # Sky
  Comment            = '#585b70'   # Overlay0
  Keyword            = '#f38ba8'   # Red
  Type               = '#94e2d5'   # Teal
  InlinePrediction   = '#45475a'   # ghost text
  ListPrediction     = '#89b4fa'
}

# ── Modules ────────────────────────────────────────────
Import-Module Terminal-Icons           # file-type icons in ls
Import-Module posh-git                  # git completions
Import-Module CompletionPredictor       # AI-style completions

# ── Useful aliases ─────────────────────────────────────
Set-Alias  vi      nvim
Set-Alias  vim     nvim
Set-Alias  g       git
Set-Alias  cat     bat                   # install: winget install sharkdp.bat
Set-Alias  ls      eza                   # install: winget install eza-community.eza

# ── Functions ──────────────────────────────────────────
function ll  { eza -la --icons --git --group-directories-first @args }
function lt  { eza --tree --icons -L 2 @args }
function gs  { git status }
function gp  { git push }
function gl  { git pull }
function gc  { param($m) git commit -m $m }
function gco { git checkout @args }

# ── Yazi wrapper (cd on quit) ──────────────────────────
function y {
  $tmp = [System.IO.Path]::GetTempFileName()
  yazi @args --cwd-file $tmp
  $cwd = Get-Content -Raw -Encoding utf8 $tmp
  if ($cwd -and $cwd -ne $PWD.ProviderPath) {
    Set-Location -LiteralPath $cwd
  }
  Remove-Item -Path $tmp
}
★

The y function is the magic Yazi wrapper — when you quit Yazi with q, your shell automatically cds into whatever directory you were browsing. This is the correct way to integrate Yazi with any shell.

07
Translucent Glass Background

Windows Terminal supports two blur modes. The Acrylic effect gives a frosted glass look; Mica (Windows 11 only) mirrors your wallpaper.

Acrylic (Win 10 + 11)
useAcrylic: true
opacity: 85
acrylicOpacity: 0.85
Mica / Acrylic (Win 11)
useAcrylic: true
experimental.useBackdropBrush: true
opacity: 80
json — settings.json → profiles → defaults
"defaults": {
  "opacity": 85,
  "useAcrylic": true,
  "experimental.useBackdropBrush": true,   // Win 11 only
  "colorScheme": "Catppuccin Mocha",
  "font": { "face": "JetBrainsMono Nerd Font", "size": 13.5 }
}
⚠

Set opacity between 80–90 for readability. Below 75 and text contrast suffers badly. The experimental.useBackdropBrush key is only supported in Windows Terminal 1.18+.

Extra Modules & Dev Tools

Install these PowerShell modules once, then they load automatically from your $PROFILE:

powershell
# ── PowerShell Gallery modules ─────────────────────────
Install-Module -Name PSReadLine           -Force -SkipPublisherCheck
Install-Module -Name Terminal-Icons       -Force   # icons in ls
Install-Module -Name posh-git             -Force   # git tab complete
Install-Module -Name CompletionPredictor  -Force   # smart predictions
Install-Module -Name PSFzf               -Force   # fzf integration

# ── CLI tools (winget) ─────────────────────────────────
winget install sharkdp.bat        # better cat with syntax highlight
winget install eza-community.eza  # better ls with icons
winget install junegunn.fzf       # fuzzy finder (Ctrl+T in PS)
winget install dandavison.delta   # better git diff
winget install cli.cli            # GitHub CLI (gh)

# ── After installing PSFzf, add to $PROFILE: ──────────
Import-Module PSFzf
Set-PsFzfOption -PSReadlineChordProvider 'Ctrl+t' -PSReadlineChordReverseHistory 'Ctrl+r'
powershell — bat + delta git config (~/.gitconfig)
# Add to ~/.gitconfig for delta as pager
[core]
  pager = delta

[interactive]
  diffFilter = delta --color-only

[delta]
  navigate    = true
  side-by-side = true
  syntax-theme = Catppuccin-mocha
  line-numbers = true

That's everything. Reload your profile with . $PROFILE and enjoy the setup!
